1

Check the claims before you pay to promote them

do this first

Google's advertising policy on misrepresentation applies directly to education businesses: any claim about certification, outcomes, or credentials "must be accurate and verifiable." Your site's own metadata leans hard on the word certification — "AI certification for professionals 2026", "chatGPT certification" — which is fine, but Google (and a disapproved-ad review) will read it literally.

Confirm each course page is clear that this is a course completion certificate, not an accredited or third-party professional certification — if that distinction isn't already stated on the course page itself, add one line to the page copy (not the metadata) before running ads to it.

Make sure pricing, refund terms, and what's included are visible on the landing page itself, not just linked from elsewhere — Google's editorial review checks the ad's destination, not just the ad text.

Your /refund-policy and /terms pages are already live and linked — good, no action needed there.

Why this matters Certification and "guaranteed outcome" language is one of the most common reasons education ads get disapproved or accounts get flagged for review. A day spent tightening this copy now is cheaper than a paused campaign later.
2

Create the Ads account & link Analytics

Go to ads.google.com → Start now → sign in with the account you want to bill (a Google Workspace/business account, not a personal Gmail used elsewhere, keeps billing and access clean).

Choose Switch to Expert Mode at setup — the guided "Smart" flow skips ad-group and keyword control you'll want for Phase 4.

Add billing details. Google Ads has no fixed minimum spend — you set the daily budget in Phase 5.

In Analytics (analytics.google.com), open Admin → Product Links → Google Ads Links for the AI Learn Hub GA4 property, and link the same Google Ads account. This is what lets Ads read conversions straight from the tag that's already on the site.

3

Set up conversion tracking — without touching the codebase

key phase

Google Ads requires at least one conversion goal before it will let you publish a Search campaign. Normally that means adding a tracking snippet to your purchase page — but GA4 is already firing on every page load, so you can define the conversion entirely inside the Analytics UI instead.

In GA4: Admin → Events → Create event. Name it course_purchase, matching condition: event_name equals page_view and page_location contains /payment-success.

Toggle that new event on as a Key event (Admin → Events → the toggle next to course_purchase).

In Google Ads: Tools & Settings (wrench icon) → Conversions → + New conversion action → Import → Google Analytics 4 properties → select the AI Learn Hub property → tick course_purchase → Import and Continue.

Set it as a Primary conversion action, count as One per click (not every).

Data accuracy, honestly The site's cookie banner (components/CookieConsent.tsx) only updates analytics_storage on accept — ad_storage stays denied by default for every visitor. That's a privacy-safe default, and Google Ads still reports conversions using statistical modeling to fill the gap, but exact per-user attribution will undercount versus a site that also grants ad-storage consent. This is a code change, so it's outside what you asked for here — flagging it only so the numbers you see later make sense. No action needed unless you want it addressed separately.
4

Build the campaign from the keyword sheet

Campaigns → + New campaign → objective Sales → type Search → conversion goal: select course_purchase (created in Phase 3).

Campaign name: AI Courses - Search — matches the Campaign column in your CSV, so anyone reconciling the two later isn't guessing.

Networks: turn off Display Network expansion and Search Partners for the first month — keeps early data clean while you learn what converts.

Locations: whatever markets you actually serve (the site is USD-priced — start with US, add others deliberately rather than defaulting to "All countries").

Bidding: Maximize Conversions, no target CPA yet — you don't have enough conversion history for Ads to optimize against a target.

Create four ad groups exactly as grouped in the CSV — one keyword theme per group keeps Quality Score high because the ad and landing page stay tightly relevant to the search term:

Negative keywords — add these before you launch Education searches attract a lot of non-buyers. Add as campaign-level negatives: free, pdf, download, torrent, jobs, hiring, salary, internship, scholarship, reddit, course free. Campaign → Keywords → Negative keywords → paste one per line.
5

Write the ads

Google requires at least 3 Responsive Search Ads worth of assets per ad group — up to 15 headlines and 4 descriptions, which it mixes automatically. Here's a starting set for the two highest-intent groups; adapt the pattern for the other two.

Ad · ailearnhub.io/courses/prompt-engineering-mastery
Prompt Engineering Mastery Course | Get Certified
Learn the exact prompt frameworks top teams use. Self-paced, lifetime access, certificate on completion. Enroll today.
Ad · ailearnhub.io/courses/chatgpt-mastery
ChatGPT for Business | Advanced Course
From basic prompts to advanced workflows. Built for working professionals. Lifetime access, no experience required.

Headlines to add alongside these (30 characters each): Prompt Engineering Certification, Learn ChatGPT for Business, AI Course for Professionals, Affordable AI Training.

Every headline and description must be true of the exact page it links to — an ad promising "certification" that lands on a page that never uses the word is a Quality Score and policy problem at once.

6

Budget & first-week bidding

Start the campaign daily budget around $20–30/day split across the four ad groups — enough for Ads to gather signal without a single bad keyword burning the week's spend.

Leave Maximize Conversions running for at least 15–20 conversions (roughly 2–3 weeks at this budget) before considering a switch to Target CPA — switching earlier than that starves the algorithm of data and usually raises cost per lead, not lowers it.

Check Search terms report (Campaign → Insights and reports → Search terms) every few days for the first two weeks — this is where you'll spot junk queries to add as negatives before they add up.

7

Publish & what happens next

Click Publish. Google's editorial review typically takes under 1 business day, occasionally up to 3 for education-category ads.

A Limited by policy or Disapproved status on a specific ad usually names the exact clause — re-read Phase 1 before appealing; most first-pass disapprovals in this category are the certification-language issue.

Once live, conversions from course_purchase can take up to 24–48 hours to appear in the Ads UI as GA4 data settles — don't judge performance before that window closes.
